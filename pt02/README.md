# Лабораторная работа № 2. Собственный трансформер

## Что сделано

Реализован небольшой авторегрессионный трансформер на PyTorch для предсказания следующего BPE-токена. В качестве корпуса используется роман Л. Н. Толстого «Война и мир». Текст приводится к нижнему регистру, «ё» заменяется на «е», слова выделяются регулярным выражением. Последние 10% слов отложены для проверки.

Для токенизации используются 1500 слияний BPE из лабораторной работы № 1. Модель состоит из эмбеддингов токенов и позиций, четырёх декодерных блоков с причинным многоголовым вниманием, полносвязной сети, остаточных связей и LayerNorm. Механизм внимания реализован вручную, без готовых слоёв Transformer и scaled dot product attention.

Обучение выполняется с помощью AdamW и функции потерь cross-entropy. Скрипт сохраняет конфигурацию модели, кривую обучения, примеры генерации на разных этапах обучения, результаты генерации с разными параметрами и сравнение с биграммной моделью.

Запуск полного эксперимента из любой папки:

```bash
python pt02/run.py
```

Быстрый режим для проверки работоспособности:

```bash
python pt02/run.py --fast
```

## Что получилось

После полного запуска сюда добавляются:
- число параметров модели, размер словаря и время обучения;
- таблица или график значений train loss и validation loss;
- четыре образца генерации на шагах 0, 100, 500 и 2000;
- сравнение жадной генерации, температур 0.7 и 1.5, а также top-p = 0.9;
- позиция начала зацикливания в жадном режиме;
- сравнение среднего количества нат на слово для биграммной модели и трансформера.

Численные результаты и тексты берутся непосредственно из файлов в `artifacts/`, сформированных скриптом.
