# Лабораторная работа № 2. Собственный трансформер

## Что сделано

Реализована небольшая авторегрессионная Transformer-модель на PyTorch для предсказания следующего BPE-токена на тексте романа Л. Н. Толстого «Война и мир».

Корпус приводится к нижнему регистру, «ё» заменяется на «е», слова выделяются регулярным выражением `[а-я]+(?:-[а-я]+)*`. Последние 10% слов отложены для проверки. Для токенизации используются 1500 слияний BPE из лабораторной работы № 1; слова преобразуются в единый поток токенов с маркером конца слова `</w>`.

Архитектура модели:
- эмбеддинги токенов и позиций;
- 4 декодерных блока;
- причинное многоголовое self-attention с 4 головами, реализованное вручную;
- полносвязные слои размерности 512;
- остаточные связи и LayerNorm;
- линейный выходной слой в словарь.

Готовые слои `nn.MultiheadAttention`, `nn.TransformerEncoderLayer` и `scaled_dot_product_attention` не используются. Обучение выполняется с помощью AdamW, learning rate 0,001 и функции потерь cross-entropy. Скрипт запускается из любой папки:

```bash
python pt02/run.py
python pt02/run.py --fast
```

В полном режиме выполняется 2000 шагов обучения с batch 32 и контекстом 128 токенов. Seed зафиксирован: 0.

### Сравнение с биграммной моделью

Оценка выполнена на первых 2000 словах отложенной части корпуса. Для биграммной модели использовано сглаживание с alpha = 0,01. Общая метрика — сумма отрицательных логарифмов вероятностей, делённая на число слов.

| Метрика | Bigram | Tiny Transformer |
|---|---:|---:|
| Число слов | 2000 | 2000 |
| Число токенов | 1999 | 3671 |
| Суммарные nats | 16379,4602 | 15750,8243 |
| Nats per word | 8,1897 | **7,8754** |
| Perplexity per word | 3603,7495 | **2631,7706** |

Transformer показал меньшее значение nats per word: 7,8754 против 8,1897 у биграммной модели. Снижение составило около **3,8%**. Таким образом, на выбранной отложенной выборке Transformer лучше предсказывает текст по этой метрике, хотя преимущество относительно небольшое.

## Что не получилось и почему

Модель пока не генерирует полностью связный литературный текст. Даже на последнем шаге встречаются повторы, неестественные словоформы и смысловые нарушения. Это ожидаемо для небольшой модели с 1,2 млн параметров, обученной всего 2000 шагов на ограниченном корпусе.

Жадная генерация зацикливается: выбор одного наиболее вероятного токена на каждом шаге может снова приводить модель к уже встречавшейся последовательности. При высокой температуре распределение становится более случайным, поэтому возрастает число искажённых слов. Умеренная температура 0,7 в данном эксперименте дала более разнообразный и относительно узнаваемый текст, но не устранила ошибки.

Validation loss в целом снижался, однако оставался выше train loss. Это указывает на разрыв между обучающей и проверочной выборками; для дальнейшего улучшения можно увеличить объём обучения и размер модели, а также исследовать влияние гиперпараметров.
